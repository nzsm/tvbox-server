影视源整合去重工具

纯本地运行 · 双击本文件即用 · 批量整合 TVBox 影视源（数据源）· 自动去重 · 自动保存（刷新不丢）

① 批量导入影视源（粘贴 TVBox 配置，多份累积 · 自动去重）

操作：每份配置粘贴后点一次「加入源池」，可反复粘贴多份累积。不同配置间的重复源自动去重（按源标识 key），同一份配置内部原样保留。 已自动容错：注释、非法空白、非法转义、误粘入的裸文本。

② 源列表（搜索 / 勾选参与导出 / 删除 / 测延迟）

源名类型标识 key数据源（api / jar）延迟

③ 直播源配置（lives）

填你自己的直播源地址，导出时写进配置 lives。URL 可以是本地相对路径（如 ./avlive.txt，文件放服务目录）或绝对网址（如 GitHub raw 链接）。留空则不生成该项。

④ 生成合并配置（勾选的源整合成一份，填进 TVBox 即用）

合并配置 = 顶层字段（spider/logo/wallpaper 等，取第一份）+ 勾选的源（sites）+ 合并的 lives/parses。下载的 .txt 已自动命名为 merged_config.txt，直接放进自建服务目录（tvbox-server 文件夹），TVBox 配置地址填 http://电脑IP:8080/tvbox.txt 即可使用。

① 批量导入影视条目（粘贴 / 文件，自动去重合并线路）

同片名+相同地址→跳过；同片名+不同地址→合并线路；缺 name/play_url→跳过。

① 输入网站 → 自动探测影视接口 → 生成 TVBox 源

原理：把网址发给本地点播服务（tvbox_server.py），由它尝试常见影视接口路径（苹果CMS /api.php/provide/vod、/api/vod、/json.php 等）。 找到标准 JSON 接口 → 直接生成一行 TVBox 源配置；找不到 → 报告页面里发现的接口线索。
